# Antigravity Project Bootstrap

Use the Skills under `.agents/skills` as the engineering playbook for this repository.

Before coding:
1. Inspect PHP/Laravel versions and installed Composer/NPM packages.
2. Inspect routes, controllers, models, migrations, Blade views, assets, tests, and existing conventions.
3. Do not introduce Livewire, Vue, React, Inertia, or third-party packages unless explicitly requested or already present.
4. Reuse existing project patterns before inventing new ones.
5. Plan authorization, validation, persistence, UI, tests, security, and performance for every meaningful feature.
6. Implement the smallest coherent change.
7. Run targeted tests and relevant lint/build checks.
8. Verify browser behavior when UI changes are involved.
9. Never run destructive production commands without explicit confirmation.
